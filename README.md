# Digital Immortality

Preserve your voice with an AI persona that learns from your conversations, memories, and preferences.

## Features

- Persona profile with editable voice and stance
- Long-term memories with pinning and search
- Preferences for tone, boundaries, and style
- Chat with AI replies (or offline fallback)
- Voice input (speech-to-text) and voice replies (text-to-speech)
- Learn-from-chat extraction for memories and preferences
- Local backup export/import
- Conversation insights and session goals

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.
